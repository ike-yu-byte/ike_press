## 为什么是 Flutter

写这个分区纯属一时兴起：白天写了太多业务代码，晚上就想用一门新语言、一个新框架，从零做点完全属于自己的东西。Dart 的 `null safety` 和 Flutter 的热重载，目前体验良好。
