# Introduction

This site is built with **VitePress** — a static site generator by the [Vue.js](https://vuejs.org/) team, powered by Vite and Vue 3, purpose-built for documentation.

## What it solves

- Write content in plain **Markdown** and focus on the writing itself
- **Sub-second hot updates** powered by Vite during development
- The build output is **pure static files**, deployable to GitHub Pages, Vercel, Netlify, Nginx, or anywhere else
- Embed **Vue components** seamlessly for interactive docs
