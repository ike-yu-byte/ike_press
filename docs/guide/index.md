# 介绍

本页站点由 **VitePress** 构建。VitePress 是 [Vue.js](https://vuejs.org/) 团队出品的静态站点生成器（SSG），底层使用 Vite 与 Vue 3，专为文档场景优化。

## 它解决什么问题

- 以纯 **Markdown** 编写内容，专注写作本身
- 开发时基于 Vite 的 **秒级热更新**
- 构建产物是 **纯静态文件**，可部署到 GitHub Pages、Vercel、Netlify、Nginx 等任意平台
- 页面中可无缝嵌入 **Vue 组件**，实现交互式文档
